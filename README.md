# અપેક્ષા AI (Apexa) — GitHub Pages લાઇવ સેટઅપ

આ ફોલ્ડરની બધી ફાઇલો સીધી GitHub પર અપલોડ કરીને 2 મિનિટમાં તમારું પર્સનલ AI લાઇવ કરી શકાય છે:

1. GitHub પર નવી **Public Repository** બનાવો (દા.ત. `apexa-ai`).
2. આ ZIP એક્સટ્રેક્ટ કરીને અંદરની બધી ફાઇલો (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `.nojekyll`) રેપોઝિટરીના રૂટમાં **Add file → Upload files** કરીને Commit કરો.
3. રેપોઝિટરીમાં **Settings → Pages** ખોલો → **Branch** માં `main` અને `/ (root)` પસંદ કરીને **Save** કરો.
4. 1–2 મિનિટમાં તમારી લાઇવ લિંક (`https://<username>.github.io/apexa-ai/`) ચાલુ થઈ જશે.
5. Android ફોનમાં Chrome માં લિંક ખોલી **Install App / Add to Home Screen** કરો અને **સેટિંગ્સ** માં તમારી Gemini API Key તથા Google Sheets Apps Script URL ઉમેરો.
